# Проверка StudyFlow

Проверено 23 ноября 2026 года после ручного разрешения конфликта в ветке `feature-2`.

## Автоматические проверки

Из папки проекта:

```powershell
py -m unittest discover -s tests -v
```

**Все 11 проверок прошли успешно.** Они находятся в `tests/test_main.py` и охватывают:

- сроки вчера, сегодня и завтра; выполненное задание с прошедшим сроком;
- сводку для пустого списка;
- удаление лишних пробелов и выдачу разных номеров новым заданиям;
- отказ от пустых полей и несуществующих дат;
- сохранение добавленного задания и отметки выполнения;
- сохранность файла при неизвестном номере задания;
- сохранность повреждённого JSON и записи без обязательных полей;
- отказ от даты в неправильном формате без создания файла;
- демонстрацию без записи в личный файл;
- сортировку списка по сроку сдачи.

## Демонстрационный пример

```powershell
py src/main.py
```

Демонстрационный запуск проверен. В примере четыре задания; для даты **23.11.2026** получен результат:

```text
Всего: 4 | Готово: 1 | Осталось: 3 | Просрочено: 1
```

Выполненное задание с прошедшим сроком учитывается как готовое. Задание со сроком сегодня не считается просроченным.

## Сохранение между запусками

Для проверки можно использовать отдельный файл, который ещё не существует:

```powershell
py src/main.py --file localdata/check.json add "Подготовить отчёт" --subject "ИТ" --due 2026-11-24
py src/main.py --file localdata/check.json list
py src/main.py --file localdata/check.json done 1
py src/main.py --file localdata/check.json summary
```

После первого запуска запись должна появиться в списке. После `done 1` сводка должна показать одно готовое задание и ноль оставшихся. Если выбранный файл уже содержал задания, нужно использовать номер, который программа сообщила при добавлении.

## Что программа не делает

Это локальный учебный помощник без регистрации, совместного редактирования и отправки уведомлений. Данные сохраняются в выбранном файле на компьютере. Для демонстрации используется отдельный набор из `data/example_tasks.json`.
