# StudyFlow — учебные задания и сроки

StudyFlow помогает студенту записывать задания по предметам, следить за сроками и отмечать выполненную работу. Это небольшая программа на Python, которой управляют командами в терминале. Тема продолжает проект из первой лабораторной работы.

У каждого задания есть номер, название, предмет, срок сдачи и отметка выполнения. Записи сохраняются на компьютере между запусками.

## Запуск

Нужен **Python 3.10 или новее**. Дополнительные библиотеки устанавливать не нужно.

```powershell
git clone https://github.com/Maddog8181/StudyFlow.git
cd StudyFlow
py src/main.py
```

В Linux и macOS вместо `py` используется `python3`.

Запуск без аргументов показывает четыре примерных задания и общую сводку. Для этого примера выбрана постоянная дата — **23.11.2026**. Поэтому результат будет одинаковым и при повторном показе. Личные записи при таком запуске не меняются.

```text
Всего: 4 | Готово: 1 | Осталось: 3 | Просрочено: 1
```

## Свои задания

Команды выполняются из папки `StudyFlow`:

```powershell
py src/main.py add "Подготовить отчёт по Git" --subject "Информационные технологии" --due 2026-11-24
py src/main.py list
py src/main.py done 1
py src/main.py summary
```

При добавлении программа сообщает номер новой записи. В команде `done 1` число `1` — номер задания, которое нужно отметить выполненным. Для следующих записей следует подставить их номера.

| Команда | Что делает |
|---|---|
| `demo` или запуск без аргументов | Показывает пример без изменения личных записей |
| `add` | Добавляет задание с предметом и сроком |
| `list` | Показывает список по сроку сдачи |
| `done` | Отмечает выполненное задание по номеру |
| `summary` | Показывает, сколько заданий всего, готово, осталось и просрочено |

**Правило срока:** невыполненное задание просрочено, если дата сдачи раньше сегодняшней. Задание со сроком сегодня ещё не считается просроченным. В личном списке используется текущая дата компьютера.

Личные записи находятся в `localdata/tasks.json`. Папка `localdata` исключена из Git, поэтому обычные команды добавления изменений не отправляют её содержимое в репозиторий. Для отдельного списка можно выбрать другой файл; параметр `--file` ставится перед командой:

```powershell
py src/main.py --file localdata/practice.json add "Повторить команды Git" --subject "ИТ" --due 2026-11-25
py src/main.py --file localdata/practice.json list
```

Программа сообщает об ошибке, если название пустое, дата указана неверно или номера задания нет в списке. Повреждённый файл данных не заменяется пустым списком.

## Файлы проекта

```text
src/main.py              программа и обработка команд
data/example_tasks.json  задания для демонстрации
tests/test_main.py       проверки работы программы
docs/git-history.md      этапы лабораторной по Git
docs/verification.md     правила и способы проверки
```

Запустить проверки:

```powershell
py -m unittest discover -s tests -v
```
